Patching every PC from the MECM console

Remoting into each PC to update it by hand is the slow path. MECM can deploy Windows, Office and third-party updates to every PC at the same time. This guide shows how.

00Check what's set up

Confirm these three things in the MECM console before deploying anything:

  • Software Update Point role existsAdministration → Site Configuration → Servers and Site System Roles
    If it's missing, Windows patching through MECM isn't set up yet. Ask the MECM admin first.
  • Updates are syncingSoftware Library → Software Updates → All Software Updates
    The list should show recent updates.
  • PCs have a healthy clientAssets and Compliance → Devices
    Look for Client = Yes and active status. Only these PCs can receive deployments.

01Windows and Office updates to all PCs at once

Step 1 · Create collections (groups of PCs)

Assets and Compliance → Device Collections → Create Device Collection
CollectionMembersPurpose
Patch - Pilot~10 PCsIT staff first. Catches broken updates before everyone gets them.
Patch - All WorkstationsEveryone elseMain rollout.

Step 2 · Clear the current backlog (one time)

Software Library → Software Updates → All Software Updates
  1. Filter the list: Required > 0, Expired = No, Superseded = No, Classification = Security Updates / Critical Updates.
  2. Select all → Create Software Update Group → Deploy to Patch - Pilot.
  3. After 1–2 days with no problems, deploy the same group to Patch - All Workstations with a deadline (for example 48 hours). After the deadline, updates install even if users ignore the notification.
This one step usually removes a big share of the findings, because the latest cumulative update replaces many older ones.

Step 3 · Automate it so you never repeat this

Software Library → Software Updates → Automatic Deployment Rules → Create
SettingValue
Date releasedLast 1 month
SupersededNo
ProductsYour Windows / Office / Microsoft 365 versions
ClassificationSecurity Updates, Critical Updates
ScheduleRun the day after Patch Tuesday

Create two rules with the same criteria:

RuleTargetDeadline
ADR - PilotPatch - PilotAs soon as possible
ADR - WorkstationsPatch - All Workstations~7 days later

After this, Microsoft patches deploy themselves every month.

02Third-party apps: Chrome, Java, Adobe and others

This is likely where most of the 20 findings per PC come from, and MECM doesn't patch these out of the box. There are two ways to handle them.

Fastest · paid

Patch My PC plugs into MECM and adds hundreds of third-party apps to the same Software Updates list.

You then deploy them exactly like section 01, including the automatic monthly rules. This is the usual answer for MECM environments.

Free · more manual

Deploy each new version as an MECM Application that replaces the old one.

Do this for the top 10 most-flagged programs, not all 20.

Free option · deploy the new version as an Application

Software Library → Application Management → Applications → Create Application
  1. Download the latest MSI, for example the Chrome Enterprise MSI or Adobe Reader.
  2. Create the application. On the Supersedence tab, add the old version and tick Uninstall, so MECM removes the old one and installs the new one.
  3. Deploy it as Required to Patch - All Workstations.

Remove leftover old versions with Run Scripts

Software Library → Scripts → Create Script

Then right-click a collection → Run Script. It runs on every PC in that collection at once.

PowerShell · remove Java builds older than a given version
Get-Package -Name "Java*" |
  Where-Object Version -lt "8.0.431" |
  Uninstall-Package -Force

A new script must be approved before it runs. By default, the person who created it can't approve it, so a second admin has to. Set the version threshold to your approved build.

Target only the affected PCs

Create a query-based collection such as “PCs where Installed Software = Java with version lower than X”, and deploy the fix only to that collection.

04Suggested order of work

  1. Week 1Clear the Windows / Office backlog (section 01, step 2), then rescan.
  2. Weeks 1–2Handle the top 10 third-party apps (section 02).
  3. Week 2Set up the automatic monthly deployment rules (section 01, step 3).
  4. OngoingAsk management about Patch My PC if the third-party work keeps coming back.
